# Revolv Gym Management System

Windows desk software for one gym: members, payments, check-in, classes, reports, and door access.

Developed by **Sn0w8irD**.

## Download

Get the latest installer from **[Releases](https://github.com/MauriceOS/Revolv-Gym-Management-Software/releases)**.

File: `RevolvGym_Setup.exe`

## What you get

- Member records and plans  
- Cash and M-Pesa payments  
- Desk check-in and door (Hikvision MinMoe)  
- Staff logins and roles  
- Classes, reports, backup/restore  
- Your gym name and logo  

## Requirements

- Windows 10 or 11 (64-bit)  
- SQL Server Express LocalDB  
- One desk PC per licence  

## Trial and licence

1. Install and start. You get a **7-day trial**.  
2. After trial, open **Licence** and copy the **Machine ID**.  
3. WhatsApp **0702669639** or email **osoromaurice02@gmail.com** with that Machine ID.  
4. You receive a key. Paste it under Licence.  

One licence = one PC. Moving to a new PC needs a transfer.

## Install notes

- Keep LocalDB installed.  
- Updating the app does not wipe your gym database if you leave the import step blank.  
- Always create a backup from Maintenance before major changes.
